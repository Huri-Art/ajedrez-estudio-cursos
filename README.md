# ajedrez-estudio-cursos
Catálogo de cursos de Ajedrez Estudio

## Número de lecciones y ejercicios del catálogo

Después de añadir o cambiar un curso, desde la raíz del repositorio:

    python actualizar_manifest.py

Cuenta las lecciones y los ejercicios de cada curso y los escribe en
`cursos/manifest.json` (`numLecciones`, `numEjercicios`), que la app muestra en el
catálogo. No hace falta contarlos a mano.
